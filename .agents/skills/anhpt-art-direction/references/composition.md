# Composition

Frame one clear focal subject before adding atmosphere. Let scene layout support
the surrounding HTML heading and copy instead of replacing them.

- Keep the focal character, badge, or object distinct from the darkest field.
- Use foreground, middle ground, and background only when they improve the
  reading order; leave calm negative space for responsive crops.
- Apply one consistent light direction per asset. Highlight planes and cast
  shadows must agree across the scene and its character.
- Use hard pixel silhouettes, stepped contours, and compact color clusters.
  Do not soften edges with blur, anti-aliasing, airbrush shading, or vector
  curves.
- Make decoration atmospheric and subordinate to semantic page content.
