# Palette

Use the active `src/styles/index.css` CSS tokens as the canonical palette:

| Token           | Value     | Role                                                 |
| --------------- | --------- | ---------------------------------------------------- |
| `--ink`         | `#14211d` | outlines and readable dark text                      |
| `--emerald-950` | `#061f1b` | deepest backgrounds                                  |
| `--emerald-900` | `#07352d` | console surfaces                                     |
| `--emerald-800` | `#0b4a3a` | structural emerald                                   |
| `--emerald-700` | `#176b4e` | highlights and labels                                |
| `--cream`       | `#f5ecd8` | dialogue and content panels                          |
| `--gold`        | `#e8b949` | achievements and sparing emphasis                    |
| `--grass`       | `#63a945` | natural accent                                       |
| `--red`         | `#a93d31` | cap, continuation markers, and primary action accent |

Favor dark emerald fields with cream readable surfaces. Gold and red should
guide attention, not cover large areas. Use discrete pixel clusters and clear
value separation instead of gradients or soft shading.
