# Typography

Typography carries meaning in the interface, not in generated raster art.
Keep all meaningful copy editable and semantic in HTML, including headings,
navigation, labels, descriptions, claims, scores, and calls to action.

| Typeface       | Interface role                                                 |
| -------------- | -------------------------------------------------------------- |
| Press Start 2P | short uppercase labels, badges, and compact game-like headings |
| Pixelify Sans  | primary display headings and navigational identity             |
| VT323          | dialogue, status, stat, and terminal-like supporting text      |

Do not render readable words, logos, signatures, UI labels, or other meaningful
text into scene, sprite, badge, icon, or decoration pixels. Non-semantic marks
such as abstract glyph-like texture are acceptable only when they cannot be
mistaken for copy.
