# Originality

Use handheld-RPG conventions as a visual vocabulary, never as material to copy.
An asset must be authored for Anh's portfolio and cannot reproduce a recognizable
game logo, franchise character, named location, map layout, scene screenshot,
or distinctive UI arrangement.

Before approval, ask:

1. Does the asset communicate an original professional-portfolio moment?
2. Would it still stand apart if familiar game names and logos were removed?
3. Are locations, props, landmarks, and symbols invented for this site?
4. Does it avoid copied logos, locations, characters, and screenshot framing?

Reject and redesign when any answer is no. Keep the emerald palette and pixel
grammar, but create new environments, props, and compositions.
