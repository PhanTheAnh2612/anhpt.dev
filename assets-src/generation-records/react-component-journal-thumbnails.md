# React component journal thumbnails

Generated as social-sharing and Journal-card artwork for the React
component design series.

## Shared specification

- Canvas: 1200×675 WebP, landscape 16:9.
- Display: responsive Journal card and Open Graph/Twitter large image.
- Palette: deep emerald and forest green, warm cream, sparing gold, muted red.
- Rendering: original polished 16-bit-inspired pixel art, crisp square clusters,
  stepped outlines, one warm light source, and readable silhouettes.
- Accessibility: decorative card thumbnails use empty alternative text; article
  titles and descriptions remain editable HTML and social metadata.
- Avoided: logos, copied interfaces, readable text, watermarks, gradients, blur,
  antialiasing, painterly texture, photorealism, and franchise imagery.

## Source-coverage expansion

The ten expansion thumbnails are generated through ChatGPT in the user’s Chrome
session, downloaded from the ChatGPT interface, visually reviewed, resized to
1200×675 with nearest-neighbor sampling, and encoded as lossless WebP.

Every prompt uses the shared render signature and its row-specific visual model.
Prompts require one clear focal metaphor, generous crop-safe negative space,
strong silhouettes at card size, no characters, no readable text, and no
recognizable product or framework logos. All ten outputs passed the contact-sheet
review for composition, crop safety, legibility at card size, and accidental
text or marks. ChatGPT returned one transient generation error for the Core Web
Vitals image; the unchanged confirmed prompt succeeded on retry.
