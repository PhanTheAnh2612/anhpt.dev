# Production pixel-art generation prompts

All assets were generated with the built-in image generation workflow. The downloaded chat images were used only to understand the approved character and visual direction; production pages do not reference them.

## Anh — Frontend Ranger

Create one full-body, front-facing pixel-art character of Anh: a friendly Vietnamese adult man with a red baseball cap carrying a small original white stitch, black rectangular glasses, a subtly patterned dark-red shirt, white cargo pants, black shoes with orange soles, a black-and-red developer backpack, wristwatch, and side utility pouch. Use polished original 16-bit handheld-RPG proportions, a readable silhouette, hard pixel edges, and no copyrighted symbols, words, or watermark.

## Coastal route

Create a 3:2 original 16-bit pixel-art coastal forest route with a winding tan path, emerald trees, flowers, a wooden cottage, blue ocean, and distant hills. Place Anh on the lower-left path in his complete Frontend Ranger outfit. Leave calm space on the right for an HTML start menu. No interface, words, logos, copyrighted characters, or watermark.

## Learning world map

Create a 3:2 original top-down fantasy software-learning map made of lush islands connected by bridges and dotted travel routes. Include forests, mountain caves, a port, a technology city, a cloud observatory, and a research tower. Leave open areas for HTML route labels. Use emerald, ocean blue, cream, and gold with hard pixel edges and no text or copyrighted locations.

## Knorex Guild Hall

Create a 3:2 original technology guild interior in warm wood, stone, and dark emerald. Center Anh and surround him with diverse engineer NPCs, abstract code-review boards, frontend monitors, a green backend terminal, an urgent-request board, bookshelves, plants, and a training corner. No real dashboards, company logos, readable text, or copyrighted game elements.

## Secret Base

Create a 3:2 cozy pixel-art developer room with a desk, abstract code monitor, window to green trees, books, journal, notes, backpack, coffee, plants, and warm lamps. Place Anh working at the desk and leave a darker area on the left for HTML notes. Use dark emerald, warm wood, cream, red, and gold; no interface, readable text, logos, or watermark.

## Achievement badges

Create eight consistent 16-bit pixel-art merit badges in a 4-by-2 grid on a dark emerald field: rookie compass, explorer sun, component crystal, state leaf, router path, TypeScript-inspired rune without an official logo, UI engineer shield, and quality guardian star. Icons only, with no labels, official logos, characters, or watermark.
